# ШТАБ — командный центр руководителя

«Вся жизнь руководителя — на одном экране»: проекты, деньги компаний и личные, команда онлайн, спорт, языки, намаз и дневник.

Демо-версия MVP: веб-приложение (PWA) с регистрацией и входом по email и паролю. У каждого аккаунта свои данные, которые хранятся на сервере и видны только владельцу аккаунта. Новый аккаунт начинается с демо-данных.

## Запуск локально

```bash
python3 main.py
```

Затем откройте http://localhost:4173. Без переменной `DATABASE_URL` сервер хранит данные в локальном файле `local.db` (SQLite).

## Публикация

На Railway сервер берёт адрес базы PostgreSQL из переменной `DATABASE_URL` и порт из `PORT`. Зависимости — в `requirements.txt`.

## Структура

- `main.py` — сервер: раздаёт сайт, регистрация, вход, сессии, хранение данных аккаунта
- `index.html` — лендинг
- `app.html` — приложение
- `css/app.css` — стили, тёмная и светлая темы
- `js/core.js` — состояние, синхронизация с сервером, права доступа, деньги, графики
- `js/seed.js` — демо-данные для нового аккаунта
- `js/views-*.js` — экраны: Пульс, Проекты, Финансы, Личное, Дневник, Команда, Доступы, Настройки
- `sw.js`, `manifest.webmanifest` — PWA
- `demo/kaspi-sample.csv` — пример выписки для импорта

## Безопасность

Пароли хранятся как хэш scrypt с солью. Сессия — случайный токен в cookie с флагами HttpOnly, SameSite=Lax и Secure (на HTTPS); в базе хранится только его хэш. Подбор пароля ограничен: 10 неудачных попыток за 15 минут с одного адреса.

## Ограничения

Ассистент и сотрудники пока существуют только как данные внутри аккаунта владельца: общего доступа для команды нет. Нет восстановления пароля и подтверждения email. Telegram-бот, ИИ-помощник на LLM и автозагрузка курсов валют не подключены.
