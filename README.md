# ШТАБ — командный центр руководителя

«Вся жизнь руководителя — на одном экране»: проекты, деньги компаний и личные, команда онлайн, спорт, языки, намаз и дневник.

Это демо-версия MVP: статическое веб-приложение (PWA) без сервера. Все данные хранятся в браузере (localStorage), при первом запуске подставляются демо-данные.

## Запуск

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173. На экране входа доступны три демо-профиля: владелец, ассистент, сотрудник.

## Структура

- `index.html` — лендинг
- `app.html` — приложение
- `css/app.css` — стили, тёмная и светлая темы
- `js/core.js` — состояние, права доступа, деньги, графики
- `js/seed.js` — демо-данные
- `js/views-*.js` — экраны: Пульс, Проекты, Финансы, Личное, Дневник, Команда, Доступы, Настройки
- `sw.js`, `manifest.webmanifest` — PWA
- `demo/kaspi-sample.csv` — пример выписки для импорта

## Ограничения демо

Нет сервера и общей базы, вход по коду — имитация, права проверяются только в браузере. Telegram-бот, ИИ-помощник на LLM и автозагрузка курсов валют не подключены.
